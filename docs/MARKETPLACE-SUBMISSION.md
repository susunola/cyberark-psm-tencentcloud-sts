## Description

Launch Tencent Cloud console role sessions through CyberArk PSM. Vault stores a dedicated caller's API credentials. An authenticated internal bridge obtains temporary role credentials from Tencent Cloud STS and signs a console login callback. PSM supplies browser session isolation and recording through its existing Web framework.
