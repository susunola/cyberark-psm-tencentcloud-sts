# 验收记录

[English](ACCEPTANCE.md)

测试包含真实环回 HTTP/Waitress 请求，STS 使用模拟；TLS/IIS 和云端端点仍待验证。CI 可以检查 Windows/Linux Python 兼容性和 PowerShell 语法，不能证明真实 PSM 或腾讯云会话可用。

| 项目 | 需保留证据 | 状态 |
|---|---|---|
| 离线测试 | 测试输出、提交、Python、依赖锁 | 本地执行，见交付报告 |
| CI | 当前提交的 Actions 结果 | 查看工作流 |
| Windows 服务 | WinSW 版本/hash、安装启动卸载、ACL | 待现场 |
| IIS 认证 | 匿名拒绝、真实 Windows 身份、头覆盖、管线顺序 | 待现场 |
| PSM 连接 | PAM/PSM、框架、浏览器/驱动、组件导出 | 待现场 |
| 腾讯云登录 | 角色信任、权限、允许控制台登录、身份核对 | 待现场 |
| 身份绑定 | `GetCallerIdentity.UserId` 是否等于 `pam/cloud.py` 校验的调用方 UIN | **部分已验证（2026-10-07）**：以国际站 CAM 子用户调用方对 `sts.intl.tencentcloudapi.com` 实测，`Type=CAMUser`、`UserId=200037920937` 等于调用方 UIN，故 `verify()` 的比较对其实际使用的长期调用密钥成立。对临时凭据不成立（其 `UserId` 为 `roleId:roleSessionName`），不得以临时凭据调用 `verify()`。 |
| 失败场景 | 错误/禁用密钥、无授权角色、MFA/网络限制 | 待现场 |
| 隔离 | 双用户双角色、并发和连续会话 Cookie | 待现场 |
| 录屏/清理 | 回放记录、审计关联、断开/超时后进程退出 | 待现场 |
| 凭据暴露 | 日志、浏览器工具、进程参数、回调 URL | 待现场 |
| 有效期 | STS、控制台 Cookie、PSM 各自实际有效期 | 待现场 |
| 升级回滚 | 版本、配置/ACL 保留、可恢复性 | 待现场 |

执行时记录测试人、日期、操作系统和组件版本，使用专用只读角色。先验证正确身份和允许操作，再验证错误密钥、缺少信任/权限、修改角色、重复字段、重放表单、匿名访问和伪造头均失败。检查双用户和双角色隔离、录屏回放、断开/超时清理、云端审计标签和 PSM 记录关联。分别测试控制台 Cookie 与 STS 有效期。完成安装、升级、回滚、卸载，确认不影响其他组件。

证据只能包含去敏截图、关联 ID 和录屏引用，不得公开完整登录链接或秘密。只有现场项目全部通过并有明确版本覆盖，才能宣称生产支持或达到成熟 AWS 连接组件的同等质量。

## 管理工具（0.3.0）

离线测试覆盖旧密钥保留、写入不确定、范围/身份核验、角色失败、显式禁写、REST 请求结构与 CVM 规划。API 调用使用模拟；真实 CAM 轮换、PVWA 纳管/审批/会话控制、客户机 SSH/RDP 需分别现场验收。见[能力边界](PAM-CAPABILITIES.zh-CN.md)。

## 共享令牌与原生操作（0.4.0）

独立 CI 验证真实 Redis 令牌并发、过期和跨节点表单消费；生产 TLS、故障转移隔离及目标 PSM 仍待验收。原生 CPM 完成状态、连接/播放响应兼容性、定时作业需现场验证。未认证原生平台/CPM 导入包。
